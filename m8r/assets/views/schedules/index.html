Schedules

When each schedule runs, in which repos, with which command, and with which prompt. A schedule has a run for each of its repos, and they start together. A run starts the command in its repo's clone, through the login shell of m8r's user, and pipes the prompt to it. The prompt gets the watchlist items of that repo: the ones of the schedule's category, and no more than its max items (0: all of them).
