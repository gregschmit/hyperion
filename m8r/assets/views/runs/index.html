m8r is up, and has nothing to do yet

m8r runs your agent as the m8r user, with the tools and logins in that user's home. It installs none of them. Become that user (sudo -iu m8r), and set its home up as you would a new computer:

  1. Install your dotfiles and tools: the agent CLI, gh, glab.
  2. Log each of them in.
  3. Clone the repos to maintain.

Then add the repos, add a schedule, and run it now.
